# APEX Racing

A browser-based 3D racing prototype built with HTML, CSS, JavaScript, and Three.js. The project explores high-speed driving, a long changing course, rival racers, and an Indian-inspired sunrise setting.

> Work in progress: this is an early playable prototype, not a finished commercial release.

## Play

After publishing with GitHub Pages, the game will be available at `https://YOUR-USERNAME.github.io/apex-racing/`. Replace `YOUR-USERNAME` with your GitHub username.

## Current features

- Long course with plains, hills, mountains, desert, village, and town regions
- Racing rivals, event choices, minimap, race HUD, and camera modes
- Indian-inspired dawn panorama with a visible sun
- Bridge-edge free fall, impact, and game-over sequence
- Keyboard and touch controls

## Controls

- **W / Up Arrow:** accelerate
- **S / Down Arrow:** brake
- **A / D or Left / Right Arrow:** steer
- **Space:** boost
- **V:** cycle camera
- **R:** restart the event
- **Q / E:** downshift / upshift when manual shifting is enabled

## Run locally

Open `index.html` in a modern browser with an internet connection. The page loads Three.js from a CDN. Audio starts after a user interaction, as required by most browsers.

## Publish with GitHub Pages

1. Create a **public** repository named `apex-racing`.
2. Add `index.html` and this `README.md` at the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. Open the published URL and test the game in a logged-out browser before sharing it.

## Project focus

This prototype is being iterated on for steering response, route readability, rival pacing, and visual reliability. Feedback on driving feel and track readability is welcome.
